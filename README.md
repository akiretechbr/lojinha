# Lojinha Akire

Catálogo público alimentado sob demanda pela aba `MULTIPLAS` da planilha de produtos.

Somente `PRODUTO` e `VENDA LOCAL` são publicados em `data/produtos.json`. O visitante pode escolher sem frete, frete de R$ 8,90 ou frete de R$ 13,90; o valor final é calculado no navegador.

Não há atualização agendada. A base é atualizada apenas quando solicitada ao Codex.
